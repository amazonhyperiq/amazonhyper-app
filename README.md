# Amazon Hypermarket App — V1

نسخة مستقلة للتطوير مبنية على ملفات الموقع الحالية، بدون تعديل ملفات الموقع التشغيلي القديم.

## المرحلة الأولى
- تحويل واجهة الزبون إلى PWA قابلة للتثبيت كأيقونة.
- Android: يمكن تثبيتها من المتصفح عبر Install app / Add to Home Screen.
- iPhone/iPad: افتح الموقع في Safari ثم Share → Add to Home Screen.
- Windows/Chrome: استخدم Install من شريط العنوان عند ظهور خيار التثبيت.

## ملاحظة
هذه المرحلة لا تنشئ تطبيق Android/iOS أصلياً ولا تغيّر قاعدة بيانات Supabase. هي طبقة PWA فوق الموقع الحالي، لذلك تبقى وظائف الموقع والربط الحالي كما هي.
