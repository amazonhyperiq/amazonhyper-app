# أمازون هايبر ماركت — Development v4

نسخة تطوير مستقلة لتحديث واجهة العميل بصرياً مع الحفاظ على وظائف المتجر الحالية.

## أهم ما تغير
- واجهة رئيسية أقرب لتطبيقات السوبرماركت الحديثة.
- بنر رئيسي احترافي قابل للتحكم من لوحة الإدارة.
- أقسام على شكل بطاقات مربعة: 5 أعمدة ظاهرة، حتى 4 صفوف، والباقي بسحب أفقي داخل منطقة الأقسام فقط.
- صور مواد/منتجات تمثل الأقسام بدلاً من Emoji للأقسام الحالية.
- الصور موحدة بصرياً وموجودة داخل `icons/categories/`.
- تحسين حجم صور الأقسام على الشاشات الصغيرة حتى لا تتجاوز البطاقات.
- الحفاظ على السلة، البحث، العروض، جدولة الطلب الاختيارية، واتساب، ولوحة الإدارة.
- Service Worker بإصدار v4 لتقليل مشاكل الكاش بعد التحديث.
