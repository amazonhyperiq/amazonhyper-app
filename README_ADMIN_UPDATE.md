# تحديث لوحة إدارة أمازون هايبر ماركت

هذا التحديث يخص لوحة الإدارة فقط، ولا يغيّر `index.html` أو تصميم الصفحة الرئيسية للزبائن.

## الملفات الجديدة/المعدلة
- `admin.html` — تصميم لوحة الإدارة، التنقل المنفصل، لوحة القيادة، البحث السريع وتعديل الأسعار، وإدارة المستخدمين.
- `login.html` — دعم تسجيل دخول مستخدمي الإدارة الجدد مع إبقاء توافق الحساب الرئيسي الحالي مؤقتاً.
- `admin_users.sql` — إعداد جداول ودوال مستخدمي لوحة الإدارة في Supabase.

## التفعيل
1. ارفع/استبدل `admin.html` و`login.html` في مستودع `amamazonhyper-new`.
2. افتح Supabase > SQL Editor.
3. الصق محتوى `admin_users.sql` وشغّله مرة واحدة.
4. بعد التنفيذ، سجّل خروج ثم ادخل بالحساب الرئيسي الحالي `omar / 200516`.
5. من «إدارة المستخدمين» أضف حسابات الموظفين وحدد الصلاحيات.

## ملاحظات
- الإحصائيات في لوحة القيادة تُقرأ من `orders` و`customers` والمواد الموجودة في بيانات الكتالوج.
- المبيعات تستثني الطلبات الملغاة.
- «الأكثر طلباً» تُحسب من تفاصيل المواد داخل الطلبات غير الملغاة.
- البحث السريع لا يغيّر اسم المادة أو القسم؛ زر «حفظ السعر» يغيّر السعر فقط.
- لا يوجد أي تغيير على المواد أو الأسعار أثناء تحميل التحديث.
- صلاحيات المستخدمين في هذه المرحلة تتحكم في وصول واجهة لوحة الإدارة؛ العمليات الموجودة أصلاً على بيانات الكتالوج تحتاج لاحقاً إلى سياسات RLS أكثر تفصيلاً إذا أردنا فرض الصلاحيات على مستوى قاعدة البيانات أيضاً.
